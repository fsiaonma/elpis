# SDD · spec → plan → tasks → implement

每个 Part 开头把三件套放进本目录。目录名叫 **sdd**，不要叫 specs：`spec.md` 只是三份里的需求分析。**写代码只发生在 implement。** 施工单开头钉三件套和当前任务，正文不另写一份规格。

    spec   做成什么样 · 稳定面 / 禁止 / 验收
    plan   准备怎么做 · 改哪 / 不改哪 / 对照
    tasks  按什么顺序 · 一节课一条
    implement  钉三件套 + 当前任务 · 施工单正文不改 · 才改代码
