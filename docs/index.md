# Elpis

Elpis 是一个面向企业中后台与 AI 应用的全栈框架：服务端基于 NestJS，前端基于 Vite + Vue3 + Element Plus，并内置基于 LangGraph 的 Agent 运行时。

业务仓库只需要按约定写 Nest 模块、页面、`model` 配置、Agent / Skill，框架负责启动、扫描、构建与运行。
